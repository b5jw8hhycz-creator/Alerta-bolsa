# Alerta Bolsa
MVP de una app web móvil para crear alertas de precio.

## Railway
- Start command: `npm start`
- No requiere variables para iniciar.
- Actualmente revisa precios aproximadamente cada minuto.
- El proveedor de precios es Yahoo Finance y puede tener limitaciones de cobertura.
- Las integraciones reales de email, Telegram, Discord, WhatsApp y push móvil se conectarán en la siguiente fase.
